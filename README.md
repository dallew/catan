# Catan Pip Calculator

A small web app for scoring Catan settlement corners by pips.

- **Quick pips:** tap up to three number tokens to get a corner's pip total (normal or 5–6 player extended board).
- **Corner builder:** set each hex's resource and number, save corners and compare a pair's resource coverage.

Live at https://dallew.github.io/catan/ — open it in Safari and use **Share → Add to Home Screen** to install it as an app. It works offline after the first launch.

When changing the app, bump `VERSION` in `sw.js` so installed copies clear their old cache.
